# Roadmap

## Foundation Run 1 — current

Toolchain, Rojo mappings, architectural boundaries, typed conventions, bootstraps, and design docs.

## Foundation Run 2 — current

Versioned domain schemas, pure validators, deterministic initiative, battle phases, fixtures, and
Linux-compatible tests. Target effects, status semantics, and battle resolution remain deferred.

## Run 3 — current

Studio-only placeholder UI, presentation mapping, local planning preview, asset registry, and future
sprite contracts. No authoritative gameplay or production artwork.

## Run 4A — current

Deterministic 3v3 initialization, deck zones, energy reservation, simultaneous private planning,
idempotent authenticated command processing, and hidden-information projection. Resolution remains
deferred.

## Later runs

1. Run 4B: Speed-ordered card resolution and battle events
2. Secure network transport and authoritative snapshot integration
3. Versioned profile persistence and creature collection
4. Genetics, breeding, items, equipment, and crafting
5. Trading with atomic server-side validation
6. PvE expeditions and AI opponents
7. Competitive PvP, production UI, animation, and asset integration

Each run should validate its contracts before adding dependent systems. Monetization and random
loot remain outside foundation scope.
