# Art Direction

Critterbound uses original, AI-assisted creature concepts curated into production-ready artwork.
Final assets should feel hand-painted, readable, and cartoon-stylized within a medieval-fantasy
world. Generated output is reference material until reviewed for originality, consistency, and
production quality.

Presentation uses a fixed-perspective 2.5D battlefield with layered 2D sprites. Animation should
separate useful layers such as body, effects, foreground, and shadows rather than require 3D
creature rigs. Card illustrations need clear silhouettes, consistent framing, and readable action
at interface scale.

Appearance genetics and combat ability genetics are independent. Visual traits must not silently
determine combat inheritance. Run 1 creates no final artwork, models, or exploration environment.
